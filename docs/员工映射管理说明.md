# 员工映射管理说明

## 页面入口
点击左侧导航栏的 **“员工映射”** 进入。

## 主要功能

### 1. 列表展示与搜索
- **实时搜索**：支持按真实姓名、微信网名、常用别名、班组、备注进行关键词过滤。
- **状态过滤**：默认仅显示“启用”状态的人员，勾选“显示停用人员”可查看全部。
- **视觉区分**：停用人员在列表中以灰色字体显示。

### 2. 映射记录维护
- **新增映射**：
  1. 点击“新增映射”按钮清空表单。
  2. 填写“真实姓名”（必填）。
  3. 填写“微信网名”或“常用别名”（至少填一项）。
  4. 点击“保存修改”。
- **修改映射**：
  1. 在表格中选择一行记录。
  2. 在右侧编辑区修改字段。
  3. 点击“保存修改”。
- **状态切换**：
  1. 选择记录后，点击“停用/启用”按钮可快速切换状态。
  2. 停用后的映射将不再参与“智能解析”阶段的自动匹配。

## 业务逻辑约束
- **唯一性建议**：建议真实姓名保持唯一，避免产生混淆。
- **多别名支持**：一个员工可以对应多个微信网名或别名，建议通过新增多条映射记录或在“常用别名”中记录。
- **软删除原则**：系统不提供物理删除功能，仅支持“停用”，以确保历史已确认记录的关联性。

## 操作日志
- 所有新增、修改、状态切换操作均会记录在系统运行日志（`logs/run_YYYYMMDD.log`）中。
- 注意：员工映射属于基础配置，其变更不会记录在 `corrections.log` 中（`corrections.log` 仅记录具体业务数据的修正）。
