# 日报生成说明

## 数据来源

日报文本当前仅基于 `parsed_records` 中 `confirm_status = confirmed` 的可信记录生成。

说明：

- `pending` 记录默认不进入日报
- `ignored` 记录默认不进入日报
- `raw_inputs` 仅用于原始追溯，不直接参与日报输出

## 页面能力

当前“日报生成”页面支持：

- 按日期生成日报
- 按项目筛选
- 按系统类别筛选
- 按工作类型筛选
- 按人员关键词筛选
- 预览日报文本
- 复制日报文本到企业微信或微信
- 导出 TXT
- 导出 Markdown

## 输出目录

日报输出目录为：

- `reports/daily/`

当前文件命名规则：

- `daily_report_YYYY-MM-DD.txt`
- `daily_report_YYYY-MM-DD.md`

## 文本规则

日报文本第一版采用“台账型 + 简短汇报型”结合格式。

当前规则包括：

- 如果某分类没有记录，则不显示该分类
- 如果 `worker_names` 为空，则显示“人员待确认”
- 如果时间为空，则显示“时间待确认”
- 如果 `duration_hours` 为空或为 0，则不计入总工时，并统计到待关注事项
- 如果 `result` 为空，则回退显示 `status`
- 文本格式适合直接复制到企业微信/微信，不使用复杂 Markdown 表格

## 日志与联网说明

- 生成日报时会写入运行日志
- 导出 TXT / Markdown 时会写入运行日志
- 当前版本不自动联网发送企业微信
- 企业微信自动同步接口仅预留，默认关闭
- 后续可扩展企业微信 Webhook 或应用消息接口

## 当前边界

本轮不实现：

- Excel 导出
- Word 导出
- PDF 导出
- OCR
- 企业微信自动发送
