# P3-B1 — scoped text submission service candidate

Parent 4c4cc423da594e870d8837accab2ef23ebab55d3, accepted P2-A Mac 70/70. This is an independent WorkFlow branch; P3-A2 UI acceptance is not assumed. Reuse IntakeService, ParserEngine and their existing transactional persistence. The new trusted-caller adapter scopes UUID request IDs by stable actor ID in a single database namespace. Submit commits raw input and backup intent only; targeted parse processes only that submission and never the global queue. Review remains human-operated via the existing review API; reported completion is not verified restoration. A status receipt reflects current review counts, not the original replay payload. Failures after commit report status unknown or retry required, never falsely report rollback. All-missing values remain unknown in metrics. This is NOT an authenticated HTTP service: a future adapter must derive actor/project scope from server authentication, enforce project permissions and storage isolation, and never trust caller-supplied identity. Reporter is not the inferred participant. Input limits are initial 16 KiB UTF-8 and 100 lines. Only manual/pasted text; no WeChat hooks, OCR/ASR, AI inference, mobile UI, production data, or public deployment. Test suite is synthetic, no runtime acceptance claimed until executed.
