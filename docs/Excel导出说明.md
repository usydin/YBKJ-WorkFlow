# Excel 导出说明

## 导出原则

1. **数据源**：Excel 导出严格基于 `parsed_records` 表中 `confirm_status = 'confirmed'` 的可信记录。
2. **过滤机制**：支持按日期、项目、系统类别、工作类型及人员关键词进行联合筛选。
3. **输出路径**：默认保存至 `outputs/excel/` 目录，文件名格式为 `维修记录_YYYY-MM-DD.xlsx`。

## Sheet 结构

### 1. 火灾报警维修记录
专门记录“火灾报警”类别的维保工作，包含日期、发现时间、完成时间、故障部位、维修方法、工时等核心字段。

### 2. 监控维修记录
记录“视频监控”类别的维保工作，增加了报修单位、电源测试、用料等监控专用字段。

### 3. 其他装置及设备
记录除火灾报警和监控之外的其他所有设备维保工作。

### 4. 维修工时统计
提供多维度的管理分析汇总：
- **按系统类别**：统计各系统的工作量与总工时。
- **按工作类型**：分析维修、巡检、测试等工作的分布。
- **按人员**：汇总每位员工参与的记录数与投入的总工时。

### 5. 导出说明
记录本次导出的基础信息、软件版本、版权信息以及本次导出的筛选条件。

## 关键字段映射

- **人工(人)**：系统会根据 `worker_names` 字段中的人员姓名（通过顿号、逗号、空格等分隔）粗略估算参与人数。
- **用时(H)**：直接取自 `duration_hours`，若为空则在统计页标记“工时待补全”。
- **故障部位**：合并了 `location` 与 `device_or_part` 字段。
- **结果**：优先使用人工填写的 `result`，若为空则使用 `status`。

## 注意事项

- **本地保存**：导出动作会自动处理文件名冲突，若同名文件已打开，可能会导致导出失败。
- **Git 忽略**：`outputs/excel/` 目录下的所有生成文件均已被 `.gitignore` 忽略，不会提交至代码仓库。
- **样式稳定性**：当前 V0.1 版本优先保证数据准确性和 Sheet 清晰度，未采用过于复杂的单元格合并或高级图表。

## 后续规划

- **模板映射**：支持根据不同项目（如康石、沧炼）自动套用其特定的 Excel 报表模板。
- **高级图表**：在统计 Sheet 中引入更美观的动态图表。
- **批量任务**：支持一次性导出跨度较长的月度或年度汇总表。
