# 运行产物与数据持久化说明

本文档说明 **友邦维保工作流系统 (维保日报通)** 在运行过程中生成的各类文件及其存储逻辑，方便运维、迁移与备份。

## 1. 目录结构概览

应用运行后，在可执行文件同级目录下会生成以下结构：

```text
YBKJ-WorkFlow/
├── 维保日报通.exe         # 主程序
├── datapool/             # 数据池（核心数据）
│   ├── sqlite/           # 数据库目录
│   │   └── ybkj_workflow.db
│   ├── jsonl/            # 原始输入记录备份
│   │   └── raw_inputs.jsonl
│   └── exports_history/  # 导出历史与快照
├── logs/                 # 日志目录
│   ├── app.log           # 运行日志
│   └── error.log         # 错误日志
├── outputs/              # 业务导出结果
│   ├── excel/            # 导出的 Excel 报表
│   └── word/             # 导出的 Word 文档（预留）
├── reports/              # 统计与质量报告
│   └── quality/          # 质量检查报告
└── config.local.json     # 本地配置（如主题设置）
```

## 2. 关键文件说明

### 2.1 核心数据库 (`datapool/sqlite/ybkj_workflow.db`)
- **用途**: 存储所有解析后的维保记录、人员信息、项目选项等。
- **备份建议**: 每日备份，或在系统迁移前手动拷贝。

### 2.2 原始输入备份 (`datapool/jsonl/raw_inputs.jsonl`)
- **用途**: 记录所有通过粘贴或文件录入的原始文本，作为数据审计和重解析的依据。
- **特性**: 仅追加模式，保证历史数据不丢失。

### 2.3 运行日志 (`logs/`)
- **用途**: 记录系统启动、服务初始化、关键操作及报错信息。
- **清理逻辑**: 目前为滚动覆盖，建议定期检查 `error.log`。

## 3. 绿色版 (Portable) 迁移指南

由于应用采用 **"Frozen Path Strategy"**，所有数据均存储在程序同级目录下：

1. **迁移**: 直接拷贝整个 `YBKJ-WorkFlow` 文件夹到新位置即可。
2. **备份**: 重点备份 `datapool/` 目录。
3. **清理**: 若需重置应用，删除 `datapool/` 和 `config.local.json` 即可（注意：这会清空所有已保存记录）。

## 4. 自检与诊断

运行以下命令可进行静默诊断：

- `维保日报通.exe --version`: 查看详细版本与版权信息。
- `维保日报通.exe --self-check`: 自动检查数据库连接、目录权限与环境完整性。
