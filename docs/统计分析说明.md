# 统计分析说明

## 数据来源

统计分析页面仅基于 `parsed_records` 中 `confirm_status = confirmed` 的可信记录。

- `pending` 记录默认不参与统计。
- `ignored` 记录默认不参与统计。
- `raw_inputs` 仅用于追溯，不直接参与统计。

## 统计维度

当前 V0.1 支持以下统计维度：

- 按人员统计
- 按项目/服务对象统计
- 按系统类别统计
- 按工作类型统计
- 明细记录查看

## 筛选条件

页面支持以下筛选项：

- 开始日期 `start_date`
- 结束日期 `end_date`
- 项目/服务对象
- 系统类别
- 工作类型
- 人员关键词

如果开始日期和结束日期都为空，则默认统计全部 `confirmed` 记录。

## 人员统计规则

- 人员统计以 `worker_names` 为核心字段。
- `worker_names` 可能包含多人，系统会按 `、`、`，`、`,`、空格、`/`、`;` 等分隔符拆分后分别统计。
- `worker_names` 为空时，记录归入“人员待确认”。
- 员工映射会直接影响 `worker_names` 的准确性，因此也会影响人员统计结果。

## 工时统计规则

- `duration_hours` 为空、无效或小于等于 `0` 时，按 `0` 统计。
- 同时这类记录会计入“未填写工时”。

## 页面说明

页面包含三部分：

- 顶部筛选区：用于限定统计范围。
- 总览卡片区：用于快速查看核心指标。
- 表格分析区：用于查看分维度结果和明细记录。

## 后续扩展

当前 V0.1 先以表格统计为主，后续可在此基础上扩展：

- 柱状图
- 饼图
- 趋势图
