# 当前阶段进展

## 阶段定位

当前阶段为 `V1.0 beta` 的“多来源原始输入池 + 智能解析 V0.1 + 待人工确认表”基础搭建阶段。

本轮重点不是实现 OCR 或导出，而是在现有 GUI 和录入闭环基础上，把系统从“能收原文”推进到“能解析、能追溯、能待确认”。

## 本次完成内容

### 1. raw_inputs 多来源扩展

- `raw_inputs` 已扩展为长期原始输入池，而不是面向截图样本的单一路径设计。
- 当前字段覆盖：
  - `id`
  - `created_at`
  - `operator_name`
  - `source_type`
  - `source_name`
  - `source_path`
  - `default_project`
  - `raw_text`
  - `status`
  - `note`
- 当前已实现输入来源：
  - `paste`
  - `txt`
  - `manual`
- 当前已预留但未实现：
  - `screenshot`
  - `batch_txt`
  - `unknown`

### 2. JSONL 原始输入备份增强

- 每次提交录入内容后，都会同步追加到 `datapool/jsonl/raw_inputs.jsonl`
- JSONL 记录已同步包含：
  - `created_at`
  - `operator_name`
  - `source_type`
  - `source_name`
  - `source_path`
  - `default_project`
  - `raw_text`
  - `status`
  - `note`

### 3. 样本目录与规则

- 已建立或确认以下目录：
  - `dataset/samples/screenshots_raw`

  - `dataset/samples/parsed_expected`
- `screenshots_raw` 中的图片仅作当前阶段本地视觉参考
- 已通过 `.gitignore` 忽略 `screenshots_raw` 下的图片文件，同时保留 `.gitkeep`

### 4. 员工网名映射预留

- SQLite 已新增 `employee_aliases` 表

  - `id`
  - `real_name`

### 5. 智能解析 V0.1

- 已补齐 `ParserEngine V0.1` 基础能力：
  - 日期识别

### 8. 人工确认页 V0.1

- 已新增“人工确认”页面
- 支持按以下条件筛选 `parsed_records`：
  - 确认状态
  - 项目
  - 系统类别
  - 工作类型
  - 关键词
- 支持选择记录后在下方表单中编辑以下字段：
  - `work_date`
  - `project`
  - `system_category`
  - `work_type`
  - `status`
  - `start_time`
  - `end_time`
  - `duration_hours`
  - `wechat_nickname`
  - `worker_names`
  - `location`
  - `device_or_part`
  - `problem_description`
  - `solution`
  - `result`
  - `note`
- `source_raw_text` 只读展示，不允许直接修改
- 支持以下状态流转：
  - 保存修改
  - 确认为有效记录
  - 忽略该记录
  - 恢复为待确认

### 9. corrections.log 留痕

- 当前所有人工确认动作都会追加写入 `dataset/corrections.log`
- 当前记录内容包括：
  - 修正时间
  - 操作员
  - 动作类型
  - 记录 ID
  - 原始输入 ID
  - 修改前快照
  - 修改后快照
  - 原始文本
  - 备注

### 10. 首页状态计数优化

- 工作台首页当前已支持以下核心状态计数：

  - 已确认记录数量
  - 已忽略记录数量

### 11. 设置页预留

- 设置页已增加“员工名单管理”说明占位
- 当前不实现完整增删改查，仅保留后续入口说明

## 当前可运行状态

当前版本已经具备以下运行能力：

- 数据录入页可继续提交文本
- `raw_inputs` 支持 `paste / txt / manual`
- 原始输入继续同步写入 SQLite 与 JSONL
- 智能解析页可读取 `pending_parse` 数据并生成 `parsed_records`
- 人工确认页可读取、修改并更新 `parsed_records`
- `corrections.log` 可沉淀人工修正记录
- 首页计数继续正常刷新
- 深色/浅色主题切换继续可用

## 本轮仍不实现

- Excel 导出
- employee_aliases 管理界面
- batch_txt 实际批量导入流程
