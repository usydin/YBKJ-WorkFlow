# 当前阶段进展

## 阶段定位

当前阶段为 `V1.0 beta` 的“多来源原始输入池 + 智能解析 V0.1 + 人工确认 + 日报文本生成”基础搭建阶段。

本轮重点不是实现 OCR 或复杂导出，而是在现有 GUI 和录入闭环基础上，把系统从“能收原文”推进到“能解析、能确认、能生成日报文本”。

## 本次完成内容

### 1. raw_inputs 多来源扩展

- `raw_inputs` 已扩展为长期原始输入池，而不是面向截图样本的单一路径设计。
- 当前字段覆盖：
  - `id`
  - `created_at`
  - `operator_name`
  - `source_type`
  - `source_name`
  - `source_path`
  - `default_project`
  - `raw_text`
  - `status`
  - `note`
- 当前已实现输入来源：
  - `paste`
  - `txt`
  - `manual`
- 当前已预留但未实现：
  - `screenshot`
  - `batch_txt`
  - `unknown`

- 已新增“人工确认”页面
- 支持按以下条件筛选 `parsed_records`：
  - 确认状态
  - 项目
  - 系统类别
  - 工作类型
  - 关键词
- 支持选择记录后在下方表单中编辑以下字段：
  - `work_date`
  - `project`
  - `system_category`
  - `work_type`
  - `status`
  - `start_time`
  - `end_time`
  - `duration_hours`
  - `wechat_nickname`
  - `worker_names`
  - `location`
  - `device_or_part`
  - `problem_description`
  - `solution`
  - `result`
  - `note`
- `source_raw_text` 只读展示，不允许直接修改
- 支持以下状态流转：
  - 保存修改
  - 确认为有效记录
  - 忽略该记录
  - 恢复为待确认

### 12. 日报文本生成 V0.1

- 已新增日报生成服务 `DailyReportService`
- 日报仅基于 `parsed_records.confirm_status = confirmed` 记录生成
- `pending` 与 `ignored` 记录默认不进入日报
- 已支持按以下条件筛选已确认记录：
  - `work_date`
  - `project`
  - `system_category`
  - `work_type`
  - `worker_names`
- 已支持统计以下摘要信息：
  - 已确认记录数
  - 火灾报警数量
  - 视频监控数量
  - 其他装置及设备数量
  - 总工时
  - 参与人员数量
  - 未填写人员记录数
  - 未填写工时记录数
- 已支持输出适合复制到企业微信/微信的日报文本
- 已支持导出：
  - `reports/daily/daily_report_YYYY-MM-DD.txt`
  - `reports/daily/daily_report_YYYY-MM-DD.md`
- 日报生成与导出动作均写入运行日志

### 13. 日报生成页面

- 已将左侧“日报生成”占位替换为真实页面
- 页面当前支持：
  - 日期输入/选择
  - 项目筛选
  - 系统类别筛选
  - 工作类型筛选
  - 人员关键词筛选
  - 生成日报
  - 复制到剪贴板
  - 导出 TXT
  - 导出 Markdown
  - 刷新筛选项
- 当筛选结果为空时，页面会提示：
  - “当前筛选条件下没有已确认记录，请先到人工确认页确认记录。”

### 14. Excel 导出 V0.1

- 已新增 Excel 导出页面，支持多维度筛选 `confirmed` 记录。
- 已实现 `ExcelExportService`，基于 `openpyxl` 生成结构化维保台账。
- Excel 包含多个 Sheet：
  - 火灾报警维修记录
  - 监控维修记录
  - 其他装置及设备
  - 维修工时统计（含人员、工作类型、系统类别维度）
  - 导出说明
- 支持基础样式美化：表头加粗、首行冻结、自动列宽、自动筛选。
- 导出文件自动保存至 `outputs/excel/`，并处理同名冲突。

## 当前可运行状态

当前版本已经具备以下运行能力：

- 数据录入页可继续提交文本
- `raw_inputs` 支持 `paste / txt / manual`
- 原始输入继续同步写入 SQLite 与 JSONL
- 智能解析页可读取 `pending_parse` 数据并生成 `parsed_records`
- 人工确认页可读取、修改并更新 `parsed_records`
- `corrections.log` 可沉淀人工修正记录
- 日报生成页支持生成、复制及导出 TXT/Markdown
- Excel 导出页支持生成多 Sheet 维保台账
- 首页计数继续正常刷新
- 深色/浅色主题切换继续可用
