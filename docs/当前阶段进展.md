# 当前阶段进展

## 阶段定位

当前阶段为 `V1.0 beta` 的基础工程骨架搭建阶段。

本轮目标不是一次性实现完整业务能力，而是先形成一个可以运行、可以扩展、可以继续迭代的本地离线维保工作流应用基础版本。

## 本次完成内容

### 1. GUI 基础骨架

- 已使用 `Python + PySide6` 建立桌面 GUI 入口
- 已完成深色左侧导航栏布局
- 已完成主工作区与卡片式首页布局
- 已建立以下导航模块占位：
  - 工作台
  - 数据录入
  - 智能解析
  - 数据池
  - 日报生成
  - Excel导出
  - 统计分析
  - 模型训练
  - 日志中心
  - 设置

### 2. 工作台首页

首页已提供以下数据卡片占位：

- 今日记录数
- 火灾报警数量
- 视频监控数量
- 其他装置及设备数量
- 总工时
- 待人工确认数量

### 3. 项目信息统一配置

已建立统一配置文件 `app/config.py`，集中维护以下内容：

- 中文名
- 工具名
- 英文名
- 版本号
- 开发者
- 版权信息
- Logo 路径
- 日志目录
- SQLite 路径
- JSONL 路径

### 4. Logo 安全加载

- 左侧导航顶部已接入 `assets/logo.png`
- 首页关于区域已接入 `assets/logo.png`
- 当 logo 文件不存在或加载失败时，界面自动显示文本占位，不会导致程序启动失败

### 5. 基础日志系统

已接入基础日志能力：

- 运行日志：`logs/run_YYYY-MM-DD_HHMMSS.log`
- 错误日志：`logs/error_YYYY-MM-DD.log`
- 已记录程序启动、关闭、未捕获异常

### 6. 数据与接口占位

已建立以下可扩展模块：

- `app/models.py`
  - 维保记录数据模型占位
- `app/database.py`
  - SQLite 数据池初始化接口
- `app/backup.py`
  - JSONL 备份接口占位
- `app/parser_engine.py`
  - `parse_text(input_text)`
  - `classify_record(record)`
  - `merge_similar_records(records)`
- `app/exporters.py`
  - `export_excel(records)`
  - `export_text_report(records)`
- `app/wecom.py`
  - 企业微信接口预留，默认关闭

## 当前可运行状态

当前版本已经具备以下运行能力：

- 可启动 GUI 主程序
- 可初始化运行目录
- 可初始化 SQLite 数据库文件
- 可初始化 JSONL 备份文件
- 可生成日志文件
- 可显示首页与模块占位页面

以下功能明确留到后续阶段，不在本轮实现范围内：

- OCR
- 复杂模型训练
- 云 API 接入
- 企业微信联网同步
- 实际 Excel 导出逻辑
- 实际日报生成逻辑

## 说明

- 本轮严格以“骨架先行、运行优先、结构清晰、便于扩展”为原则
- 所有路径均通过项目目录推导，不写死系统绝对路径
- 当前部分模块为占位接口，便于后续直接接入真实业务逻辑
