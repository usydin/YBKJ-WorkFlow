# 当前阶段进展

## 阶段定位

当前阶段为 `V1.0 beta` 的“多来源原始输入池 + 智能解析 V0.1 + 人工确认 + 日报/Excel/统计分析”基础搭建阶段。

本轮重点不是实现 OCR 或复杂预测，而是在现有 GUI 和录入闭环基础上，把系统从“能收原文”推进到“能解析、能确认、能导出、能统计”。

## 本阶段收尾验收

### 已完成收口

- 人工确认页已调整为“上方待确认表格 + 下方详情编辑”的主 `QSplitter` 布局。
- 详情区已使用 `QTabWidget` 收口为三个页签：
  - 基础信息
  - 处理信息
  - 原始文本
- 基础信息页已改为双列网格，减少纵向堆叠；处理信息页已整理为 `2x2` 文本区；原始文本页独立只读展示。
- `QComboBox` 下拉箭头已恢复为 SVG 资源方案，浅色/深色主题分别使用对应箭头资源。
- 员工映射逻辑已回归验证：
  - `王权富贵 -> 王立彦`
  - `王权富贵Dr. -> 王立彦`
  - `ybkj-pL -> 空`

### 当前已知问题

- 人工确认页的可用性已明显改善，但分隔条拖动手感、字段密度和按钮留白仍建议继续通过真实业务数据做人工体验确认。
- macOS 环境下运行时偶见输入法相关系统日志告警，不影响当前业务流程，但仍建议后续持续观察。
- `dataset/corrections.log` 属于运行留痕文件，提交前不应纳入版本提交。

### 下一步建议

1. 用真实待确认样本继续手测人工确认页，重点观察长文本和小窗口尺寸下的可读性。
2. 为人工确认页补充更细的批量操作或时间校验，但不在当前收尾提交中展开。
3. 在后续版本再考虑 Word / PDF、OCR 或更复杂统计图表，不纳入本阶段提交。

### 12. 日报文本生成 V0.1

- 已新增日报生成服务 `DailyReportService`
- 日报仅基于 `parsed_records.confirm_status = confirmed` 记录生成
- `pending` 与 `ignored` 记录默认不进入日报
- 已支持按以下条件筛选已确认记录：
  - `work_date`
  - `project`
  - `system_category`
  - `work_type`
  - `worker_names`
- 已支持统计以下摘要信息：
  - 已确认记录数
  - 火灾报警数量
  - 视频监控数量
  - 其他装置及设备数量
  - 总工时
  - 参与人员数量
  - 未填写人员记录数
  - 未填写工时记录数
- 已支持输出适合复制到企业微信/微信的日报文本
- 已支持导出：
  - `reports/daily/daily_report_YYYY-MM-DD.txt`
  - `reports/daily/daily_report_YYYY-MM-DD.md`
- 日报生成与导出动作均写入运行日志

### 13. 日报生成页面

- 已将左侧“日报生成”占位替换为真实页面
- 页面当前支持：
  - 日期输入/选择
  - 项目筛选
  - 系统类别筛选
  - 工作类型筛选
  - 人员关键词筛选
  - 生成日报
  - 复制到剪贴板
  - 导出 TXT
  - 导出 Markdown
  - 刷新筛选项
- 当筛选结果为空时，页面会提示：
  - “当前筛选条件下没有已确认记录，请先到人工确认页确认记录。”

### 14. Excel 导出 V0.1

- 已新增 Excel 导出页面，支持多维度筛选 `confirmed` 记录。
- 已实现 `ExcelExportService`，基于 `openpyxl` 生成结构化维保台账。
- Excel 包含多个 Sheet：
  - 火灾报警维修记录
  - 监控维修记录
  - 其他装置及设备
  - 维修工时统计（含人员、工作类型、系统类别维度）
  - 导出说明
- 支持基础样式美化：表头加粗、首行冻结、自动列宽、自动筛选。
- 导出文件自动保存至 `outputs/excel/`，并处理同名冲突。

### 15. 统计分析 V0.1

- 已新增 `AnalyticsService`，统计范围严格限定为 `parsed_records.confirm_status = confirmed`。
- 已新增 `list_confirmed_records_for_analytics()` 查询接口，支持：
  - `start_date`
  - `end_date`
  - `project`
  - `system_category`
  - `work_type`
  - `worker_names`
- 已新增“统计分析”页面，支持：
  - 总览卡片
  - 按人员统计
  - 按项目统计
  - 按系统类别统计
  - 按工作类型统计
  - 明细记录查看
- 人员统计以 `worker_names` 为核心字段。
- `worker_names` 为空时归入“人员待确认”。
- `duration_hours` 为空或无效时按 `0` 统计，并计入“未填写工时”。
- 页面底部已预留后续扩展说明：
  - 可增加柱状图
  - 可增加饼图
  - 可增加趋势图
