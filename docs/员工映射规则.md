# 员工映射规则

## 背景

微信长图或聊天记录中显示的往往是微信网名，而不是标准员工姓名。

因此系统不能直接把微信网名当作真实姓名写入最终结构化记录，必须预留“员工名单 / 微信网名映射”机制。

## 当前表设计

系统已预留 SQLite 表：`employee_aliases`

字段包括：

- `id`
- `real_name`
- `wechat_nickname`
- `alias`
- `team`
- `is_active`
- `created_at`
- `updated_at`
- `note`

## 当前 V1.0 规则

1. 系统优先尝试识别消息发送人或微信网名
2. 如果 `employee_aliases` 中能匹配：
   - 将其映射为真实姓名
3. 如果不能匹配：
   - 保留原始微信网名
   - 标记 `employee_confirm_required = true`
4. 后续人工确认时：
   - 操作员可以把微信网名修正为真实姓名
5. 人工修正结果后续可写入 `dataset/corrections.log`

## 设计原则

- 微信网名不等于真实姓名
- 原始昵称必须保留，便于追溯
- 映射结果允许人工覆盖
- 映射表应支持多别名与班组信息
- 不应在解析阶段因无法识别真实姓名而丢弃记录

## 当前界面状态
